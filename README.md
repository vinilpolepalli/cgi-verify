# CGI Verify

Demo built by Vinil Polepalli (vinilpolepalli.com) as a project for Computable (getcomputable.com).

Independently recomputes the Computable Global Index from a real snapshot pulled from market.getcomputable.com, shows the recomputed vs published value with the gap flagged, and includes a stress-test panel for weight shocks.

Static export of a Next.js app. Built with Claude Code.
